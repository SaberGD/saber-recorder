# Saber Recorder — إكستنشن تسجيل المحاضرات

إكستنشن كروم بتسجّل المحاضرة أونلاين (Google Meet أو غيره):

- **الشاشة كلها**: اللي بيتشارك وظاهر للطلبة، حتى لو الميتينج متصغّر.
- **صوت الجهاز والميتينج**: أصوات الطلبة وأي صوت طالع من الجهاز.
- **المايك**: صوت المدرب.

وبتحفظ التسجيل **على الجهاز** و/أو **ترفعه تلقائي على Google Drive** وهو بيتسجّل.

## المميزات

| | |
|---|---|
| مصادر التسجيل | الشاشة وصوت الجهاز والمايك. أي واحد فيهم يتقفل قبل البدء أو أثناء التسجيل، وبيظهر إشعار. |
| الحفظ | محلي في `Downloads/Saber Recordings` و/أو رفع تلقائي على Drive. الافتراضي الاتنين. |
| الجودة | موفّر ≈ 300 ميجا/ساعة، **متوازن ≈ 500 ميجا/ساعة (زي زووم، الافتراضي)**، عالي ≈ 1 جيجا/ساعة. |
| الأمان من الضياع | التسجيل بيتكتب على الجهاز كل ثانيتين. لو كروم قفل أو الجهاز فصل، اللي اتسجل بيظهر في "تسجيلات محتاجة متابعة" ويتكمل. |
| الرفع | قطعة قطعة وانت بتسجّل. لو النت فصل بيكمّل من مكانه لوحده. |
| التنبيهات | أيقونة `REC` على الإكستنشن، إشعار عند البدء والإيقاف، تحذير لو المايك مش بيلقط صوت أو صوت الطلبة مش بيتسجّل. |

## الإعداد (مرة واحدة)

### 1) تجهيز Google Drive في Google Cloud

استخدم **نفس مشروع Google Cloud** اللي فيه `GOOGLE_CLIENT_ID` بتاع السيستم:

1. **APIs & Services → Library**: فعّل **Google Drive API**.
2. **OAuth consent screen → Data access (Scopes)**: ضيف الصلاحية `.../auth/drive.file`.
   - دي صلاحية "غير حساسة": الإكستنشن تشوف الملفات اللي هي رفعتها بس، مش Drive كله، ومش محتاجة مراجعة من جوجل.
   - لو الـ consent screen لسه في وضع **Testing**، ضيف إيميلات المدربين في **Test users**، أو حوّله لـ **In production**.
3. **Credentials**: افتح الـ OAuth Client من نوع **Web application** (نفس بتاع السيستم أو واحد جديد)، وفي **Authorized redirect URIs** ضيف بالظبط:

   ```
   https://koaoinnnobkcaabcgnhiajnolamnceoi.chromiumapp.org/
   ```

4. انسخ الـ **Client ID** وحطه في `config.js`:

   ```js
   OAUTH_CLIENT_ID: '1234567890-xxxx.apps.googleusercontent.com',
   ```

> الـ ID بتاع الإكستنشن (`koaoinnnobkcaabcgnhiajnolamnceoi`) ثابت على كل الأجهزة بسبب حقل `key` في `manifest.json`، فمتغيّرش الحقل ده.

### 2) تسطيب الإكستنشن على جهاز المدرب

1. افتح `chrome://extensions`.
2. فعّل **Developer mode** من فوق على اليمين.
3. اضغط **Load unpacked** واختار فولدر `extension/meet-recorder`.
4. ثبّت الأيقونة في شريط الأدوات (علامة البازل ← الدبوس جنب Saber Recorder).

## طريقة الاستخدام

1. ادخل الميتينج، واضغط على أيقونة **Saber Recorder** وانت واقف على تاب الميتينج.
2. اكتب اسم المحاضرة، واختار هيتسجّل إيه والجودة ومكان الحفظ.
   أول مرة: اضغط **ربط حساب Google** علشان الرفع على Drive.
3. اضغط **ابدأ التسجيل**. هتفتح لوحة التسجيل، وتقدر تجرّب المايك فيها وتختاره.
4. اضغط **اختار الشاشة وابدأ التسجيل**، واختار **الشاشة بالكامل (Entire screen)** وعلّم على **مشاركة صوت النظام (Share system audio)**.
5. صغّر اللوحة واشرح عادي. تقدر توقف مؤقت أو تقفل أي مصدر من اللوحة، أو تنهي التسجيل من أيقونة الإكستنشن.
6. بعد الإنهاء: الملف بيتحفظ في `Downloads/Saber Recordings`، وبيكمل رفع على Drive في فولدر **Saber Group - تسجيلات المحاضرات**.
   **متقفلش لوحة التسجيل لحد ما تكتب "التسجيل اتحفظ".**

## ملاحظات

- **كروم بس** (نسخة 116 أو أحدث).
- **صوت الطلبة على الماك:** كروم على الماك مش دايمًا بيقدر ياخد صوت النظام، فالإكستنشن بتسجّل صوت تاب الميتينج مباشرة بدلًا منه. علشان كده لازم تفتح الإكستنشن **من تاب الميتينج**.
- **صيغة الملف WebM (VP9 + Opus):** دي الصيغة الوحيدة اللي كروم بيكتبها أول بأول. MP4 في كروم مبيطلعش غير لما التسجيل يخلص، فلو الجهاز فصل كان التسجيل كله هيضيع. الملف بيشتغل على VLC وكروم والويندوز 10/11.
- **التسجيل اللي اتقطع** بيشتغل عادي بس آخر ثانيتين ممكن ميكونوش فيه.
- **النشر بعدين على Chrome Web Store (Unlisted):** الستور بيدي الإكستنشن ID جديد، فلازم تضيف الـ redirect URI بتاعه كمان في الخطوة 1-3.

## الملفات

| الملف | الوظيفة |
|---|---|
| `manifest.json` | تعريف الإكستنشن والصلاحيات |
| `config.js` | الإعدادات: Client ID والفولدرات والجودة |
| `popup.html/js` | الشاشة اللي بتفتح من الأيقونة: إعداد التسجيل والتسجيلات اللي محتاجة متابعة |
| `recorder.html/js` | لوحة التسجيل: الالتقاط ودمج الصوت والتحكم والحفظ |
| `background.js` | فتح اللوحة، أيقونة REC، ربط جوجل، واكتشاف التسجيلات اللي اتقطعت |
| `lib/drive.js` | تسجيل الدخول بجوجل والرفع على Drive |
| `lib/uploader.js` | الرفع قطعة قطعة مع الاستكمال بعد انقطاع النت |
| `lib/local-file.js` + `lib/storage-worker.js` | كتابة التسجيل على الجهاز أول بأول |
| `lib/webm-duration.js` | إضافة مدة الفيديو للملف المحلي علشان التقديم والتأخير يشتغلوا |
| `lib/recordings.js` | بيانات التسجيلات وحالاتها |
